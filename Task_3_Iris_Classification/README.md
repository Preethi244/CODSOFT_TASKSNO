# Iris Flower Classification

## Objective

The objective of this project is to classify Iris flowers into three species:
Iris-setosa, Iris-versicolor, and Iris-virginica using machine learning.

## Dataset

The dataset contains 150 Iris flower samples with four measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm

Logistic Regression

## Methodology

1. Load the Iris dataset.
2. Separate features and target.
3. Split the dataset into training and testing data.
4. Train a Logistic Regression model.
5. Predict the species of test flowers.
6. Evaluate the model using accuracy and a confusion matrix.
7. Visualize the flower measurements.

## Result

The model achieved 100% accuracy on the test split used in this project.

## Visualizations

The project includes:

- Confusion Matrix
- Petal Length vs Petal Width visualization

## Conclusion

The Logistic Regression model successfully classified the Iris flower species based on their measurements.
