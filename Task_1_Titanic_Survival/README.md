# Titanic Survival Prediction

## Objective
The objective of this project is to build a machine learning model
that predicts whether a Titanic passenger survived or not.

## Dataset
The Titanic dataset contains passenger information such as:
- Passenger class
- Gender
- Age
- Number of siblings/spouses
- Number of parents/children
- Fare
- Port of embarkation
- Survival status

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Logistic Regression

## Steps
1. Loaded the Titanic dataset.
2. Checked and handled missing values.
3. Selected relevant features.
4. Converted categorical data into numerical values.
5. Split the data into training and testing sets.
6. Trained a Logistic Regression model.
7. Predicted passenger survival.
8. Evaluated the model using accuracy and a confusion matrix.
9. Created visualizations to understand survival by passenger class.

## Model Performance
The Logistic Regression model achieved approximately **81.01% accuracy** on the test data.

## Visualizations
The project includes:
- Titanic Survival Confusion Matrix
- Titanic Survival by Passenger Class

## Conclusion
The machine learning model was able to predict Titanic passenger
survival with approximately 81.01% accuracy.
